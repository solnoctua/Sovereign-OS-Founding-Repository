# Sovereign OS

> **More life. Less interface.**  
> **Maximum capability. Minimum interface. Human agency first.**

**Status:** founding draft, October 16, 2026. This is the **initial constitutional and architectural repository**, not yet a functioning OS, security-certified implementation, or released hardware product.

Sovereign is a long-lived, AI-native personal computing and intelligence environment that should deepen human agency, understanding, creativity and presence—while preserving control over memory, permissions, identity and exit. Models, frontends and future devices are interchangeable around a user-controlled core.

## Status and operating rules

- `main` should only carry reviewed choices. Constitutional ratification is pending.
- Do not commit API tokens, vault data, recordings, imported personal conversations, or encryption keys.
- Keep the Git repo as code and design authority; store private personal state in a **separate encrypted vault** with independently tested backups.
- An automated coding agent may propose edits but may not ratify changes to the Constitution or increase its own permissions.

## First demonstration

An iPhone/Mac thought is captured, preserved with provenance, recalled accurately through a replaceable model, corrected/deleted successfully, and restored from a portable backup. A prohibited tool action fails with an auditable reason.
