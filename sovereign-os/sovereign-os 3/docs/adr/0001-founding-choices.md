# ADR-0001 — Initial founder decisions

- **Date:** 2026-10-16
- **Status:** Founder choices CONFIRMED; constitutional implementation remains PROPOSED
- **Scope:** Sovereign OS first-principles design

## Context

Four strategic questions were put to the founder following the Constitution and Architecture v0.1 proposal. The founder explicitly selected the options below.

## Decisions

1. **Local-first with permissioned cloud intelligence**. Durable state and authorization remain within user control; remote inference is permitted only with scoped disclosure policy.
2. **Personal lifelong OS first**. Design and measure usefulness for one person first; maintain open contracts for possible future multi-user product.
3. **Useful, overridable challenge**. Critique unsupported assumptions and conflicts with user-declared aims; permit direct-answer/dismissal controls. Security policy remains independent.
4. **Risk-based memory approval with provenance**. Capture and inference do not confer authority. Permit bounded automatic promotion of low-risk claims; approval for sensitive, consequential, identity-shaping claims.

## Consequences

- Remove these items from open constitutional questions.
- Draft Articles I, II, IV, V, VI, VIII and X accordingly; amendments require separate ratification.
- Define specific boundaries through later ADRs and tests: provider/data policy, memory sensitivity, local vault/recovery and offline mode.
- Record external-source audit gap: complete Kimi and pinned materials not yet confirmed.

## Reversal

The founder can revise any strategic decision through a new explicit decision record. Ratified constitutional text, once it exists, must be amended through the constitutional process rather than silently edited.
