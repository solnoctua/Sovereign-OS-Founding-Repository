# Sovereign graph — synthetic example

Open **Graph view** in Obsidian. Follow the project [[EX-Project-01]] through [[EX-Claim-01]] and the original [[EX-Source-01]], then follow [[EX-Concept-01]].

**All nodes in this folder are fictional demonstration data.** Graph lines represent untyped wiki links. Relationship semantics live in the named sections of each note, not in the line itself.

Start with [[EX-Project-01]] or open **Local graph** to see its neighborhood. Read the [Obsidian design guide](../LEVELS-AND-OBSIDIAN.md) in the repository for the proposed governed exporter.
