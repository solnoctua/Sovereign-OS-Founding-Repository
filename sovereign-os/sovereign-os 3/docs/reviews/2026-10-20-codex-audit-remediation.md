## Reconciliation with PR #4

- **Ownership:** Benchmark 0003 is PR #4's executed retrieval evaluation (`docs/benchmarks/0003-retrieval-evaluation.md`). PR #3's draft `docs/benchmarks/0003-second-brain-retrieval-evaluation.md` was moved to `docs/second-brain/SECOND-BRAIN-VALIDATION.md` and rewritten (Git records a delete and an add, because the content changed substantially), narrowed to the provenance graph, Obsidian projection, future structured-relationship and temporal tests, semantic experiments (inside PR #4's harness) and optional answer evaluation.
- **No copying:** none of PR #4's files, harness or results were copied or cherry-picked. PR #3 references PR #4 by URL and by code-formatted path, never by a relative link to a file that does not yet exist on `main`.
- **Merge compatibility:** PR #3 no longer edits the *Current progress* line of `ROADMAP.md` that PR #4 rewrites; `git merge-tree` of the final PR #3 head with PR #4 is clean, as is PR #3 onto `main`.
- **Evidence and intentions:** PR #4's results and the founder's intended positions are recorded as R1–R7 in ADR-0005 §12.2, labelled pending formal approval: Porter only as a separate Tier 2 change with its precision cost stated; IDF/BM25 deferred and the fingerprint never weakened for convenience; provenance relevance unchanged; precision first; budgets unchanged; embeddings deferred; PR #4's framework retained.
- **Open PR #4 decisions:** its decision 1 (stemmer implementation) is left to the SB-4 PR; its decision 2 (accept stale previews or bind an order-preserving projection under weighted scores) needs an ADR-0004 amendment either way, because weighted scores reverse ADR-0004's statement that irrelevant changes do not invalidate an approval; its decision 6 (a private, never-committed evaluation on real notes) stays open under the Security Gate. ADR-0005 §12.2 records all three.
- **Known review dependency:** PR #4's open Codex P2 (unreproducible scale timings) must be fixed on PR #4. PR #3 relies on none of those timings.
