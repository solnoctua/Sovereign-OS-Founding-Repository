**Purpose:** distinguish the founder's established intentions from assistant-derived implementation proposals and still-unverified sources. This file is not imported personal memory.

## Recovered project direction from earlier discussions

- **August 23, 2026, 'Estimate Kimi Costs' / Sovereign OS thread:** user identified Sovereign as a 10+ year life project, adaptable to future models and potentially AGI, without loss of identity, memory, sovereignty or control; emphasized judgment, learning, agency, efficiency and living presently.
- **August 23, 2026 architectural proposals:** durable event/history substrate, portable state, model replacement, identity, permissions, provenance, memory claims, context compiler, model routing, a Cognitive Governor and separated Stable/Next/Lab experimentation. Proposals should not be confused with final founder approval.
- **October 6, 2026 model economics discussion:** high intelligence with controlled API costs; model-switching by task, development subscription versus runtime usage, Kimi as a practical development/model option rather than a permanent dependency.
- **October 8, 2026 Pocket discussion:** minimalist, largely screenless phone-like experience; magnetic card prototype possibilities; iPhone and Mac first; private audio; preserving presence; sufficiently capable silent interaction for long sensitive communications; longer-term standalone hardware and interface research.
- **October 15–16, 2026 agent-trust work and recent thread:** independent authorization, external action receipts, cryptographic provenance and revocability; relevant future extension, not required blockchain in V0.
